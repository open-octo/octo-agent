# 文案打磨（Copy Editing）

通过多轮聚焦的"扫一遍"逐层改进文案，不指望一次读改完。核心：**改是增强，不是重写**——保留作者的声音，只把清晰度、说服力、具体程度提上去。

## 动手前先确认

最多问 2-3 个：
- **目标动作**：这条要读者做什么？（决定"零风险"和 CTA 该优先扫哪）
- **受众**：谁看、什么认知？（校准"所以呢""具体""情绪"三遍）
- **风格基准**：有没有品牌调性/风格要求？（决定"语气"这一遍怎么判）

用户甩来一句"随便改改"，就先按通用标准 + 把假设列开头。

---

## 七遍打磨法（Seven Sweeps）

按顺序走七遍，每遍只管一个维度。**每改完一遍，回头确认前面几遍没被改坏**。

### 第一遍：清晰度
- 每句话能不能一次读懂？长句拆开。
- 代词指代是否清楚（"它"到底指谁）？
- 黑话、内部词有没有解释？一句话塞了三个观点就拆。

| 问题 | 改法 |
|------|------|
| 一句超过 30 字 | 拆成两句 |
| 抽象表述 | 换成具体例子 |
| 重点埋在中间 | 挪到段首 |
| 未定义缩写 | 首次出现写全称 |

### 第二遍：语气与声音
- 现在这个声音统一吗？会不会一段俏皮、一段官方？
- "我们"和"我司"混用？→ 统一。
- 收缩率、句式是否来回横跳？
- 有没有忽然冒出来一句不合调的梗？

### 第三遍：So What（所以呢）
- 每个卖点是不是都回答"我凭什么要在意"？
- 光讲功能没有后果的，补一句"哪意味着……"。

| 只讲功能 | 功能+利益点 |
|---------|-----------|
| "我们用了 AI 分析" | "我们的 AI 能把你会漏掉的洞挖出来，让你决策快一半" |
| "实时看板" | "现在就能看到正在发生什么，不用等上周的报表" |

### 第四遍：证明给我
- 每个说法是不是有依据？
- 实名客户反馈 > 具体数字 > 案例引用 > 第三方认证 > 模糊说法（"客户都说好"）。

| 证明强度 | 例子 |
|---------|------|
| 强 | "Stripe 营销 VP 陈莎：'把我们的搭建时间砍了 60%'" |
| 强 | "2847 个团队每天在用" |
| 弱（标记出来） | "行业领先""深受喜爱"——没有来源就标出来，别瞎补证据 |

凡是要用户才能提供的证据（真实客户名、真实数字），**明确标注"需你补充"**，你能改措辞但不能编证据。

### 第五遍：具体
模糊词换成可验证的具体数字。

| 模糊 | 具体 |
|------|------|
| 省时间 | 每周省 4 小时 |
| 很多客户 | 2847 个团队 |
| 很快 | 14 天见效 |
| 流程更顺 | 周报从 4 小时压到 15 分钟 |
| 服务好 | 平均响应 2 小时 |
| 好用 | 10 分钟上手，不用写代码 |
| 便宜 | 每月 29 元起 |

**铁律**：没法说具体的，多半是废话，砍掉或换成可验证的东西。

### 第六遍：情绪
文案让读者有感觉了吗？
- 痛点场景画得生动
- 前后对比让人有获得感
- 见证区释放"同侪压力"（别人都在用）
- 微故事（1-2 句具体画面）

### 第七遍：零风险
靠近 CTA 的所有摩擦力都拆掉了吗？
- 点了之后会发生什么很清楚
- 异议在 CTA 的"两屏内"就被处理
- 信任信号可见（退款、认证、人数）
- 下一步写具体（"开始 14 天免费试用"不是"立即开始"）
- 风险逆转写明白（无理由退款、免绑卡、随时取消）

**这遍优先于一切**——先把 CTA 周围改好，再去抠前面的段落。

## 快速精简版（不想走七遍）

1. 删废话：非常、真的、其实、就是、基本上、可以说
2. 弱动词换强：利用→用、有利于→帮、实现→做成
3. 被动改主动："报表由系统生成" → "系统自动生成报表"
4. 一句一个观点
5. 检查 CTA 有没有行动力

## 常见问题与改法

| 症状 | 改法 |
|------|------|
| 一堆功能列在哪，没讲为什么 | 每个后面补"哪意味着……" |
| 企业腔 | 问一句"一个正常人会怎么说？" |
| 开头弱 | 用读者的痛点/想要的结局开头，别讲公司历史 |
| CTA 藏太深 | 提前、放显眼、多次出现 |
| 没证明 | 加具体数据、实名反馈、案例引用 |
| 空泛 | 说清是谁、怎么做、多少 |
| 恨不得啥都讲 | 只留最关键的 3-5 个利益点 |
| "最高提升 50%"这类虚词 | 给中位数/典型值，带上下文 |

## 给客户交差时的呈现

改完按这个结构给用户：
1. **一句话总结**改了哪几层
2. **改前 / 改后**对照（挑最关键的 2-3 处）
3. **为什么这么改**（每处一句理由）
4. **标记需你补充**的证据/数据清单

绝不要只甩一版"改好的"让人猜你动了哪。
