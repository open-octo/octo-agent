   (https://github.com/Golden2002/legal-research-skill, commit

2. "legal-assistant-pro" in lawyerwangbo/legal-assistant-pro

   ("引用验证：严禁编造法条案例") independently corroborate the same
   official-source list and no-fabrication principle, cross-checked
   against source 1.

Modifications for octo: removed source 1's paid commercial database
integration (Wolters Kluwer / 威科先行 API credential collection and
config.json write flow, an entire "威科先行 API 确认与配置" workflow
section), its bundled Python modules (mcp_server.py, legal_validator.py,
case_retriever.py, legal_reasoning.py, the web/ panel, the use_database_by_
api/ adapter) — none of it is used, referenced, or ported; this skill is
prose-only per octo's skill convention. Also removed the source's
identity-branching flow built around a specific "AskUserQuestion" tool
call and its docx-export option, both of which assume tooling this
profile does not have. The identity-based report differentiation (普通人/
法学生/律师/法官检察官/企业法务) was not ported — legal-helper's own system
prompt already handles audience adaptation without a forced multi-step
tool-driven intake flow.
