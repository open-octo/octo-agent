# 转化文案（Copywriting）

写清楚、有说服力、能推动行动的文案。核心原则：**清晰大于炫技、卖点转利益点、具体胜过空泛、讲人话而不是讲公司话**。

## 动手前先问清楚（别瞎猜）

最多问 2-3 个最影响产出的，其余自己带 default：

- **页面/内容类型**：落地页、首页、定价页、功能页、产品介绍、广告语？（决定结构）
- **唯一目标动作**：这一条内容要读者做一件什么事？（先定 CTA，全文为它服务）
- **目标人群 & 认知阶段**：他们是谁、对你了解多少？（选框架和 CTA 门槛）
- **核心差异点**：最值得先讲的那一个好处（驱动标题和首屏）

用户说"先随便写一版"就写，把假设列在开头。

## 核心原则

### 1. 卖点转利益点（Features → Benefits）
写产品功能不是目的，写它给用户带来的结果。

| 卖点 | 利益点 |
|------|--------|
| "实时数据看板" | "一眼看清现在什么在赚，不用等周报" |
| "AI 推荐" | "给的建议是真的贴合你的数据，不是通用套路" |
| "99.99% 可用性" | "你的客户永远不用面对打不开的页面" |
| "SOC 2 认证" | "过企业的安全审查不用再折腾半年" |

### 2. 具体胜过空泛
- 空泛："帮你省时间" → 具体："每周做周报从 4 小时压到 15 分钟"
- 空泛："数万用户的选择" → 具体："2847 个团队在用，包括 Stripe、Notion"

### 3. 说人话（讲客户的话，不是公司的话）
用客户在评价/工单/销售通话里会用的话，别用市场部黑话。

### 4. 一段一个观点
按"问题 → 方案 → 证明 → 行动"往下推，不要一段塞三件事。

### 5. 诚实胜过夸张
绝不编数字、编见证、编夸大。具体 + 诚实比打鸡血更能换来信任。

## 文案框架

### PAS：问题 → 激化 → 方案
适合落地页、标题、广告、产品页。
```
[痛点]：用读者的语言说出那个痛
[激化]：不解决会怎样（失去什么/代价）
[方案]：介绍你的产品是答案
```
> 你的团队每周花 4 小时手动整理报表。一年 200 小时，相当于白白丢了一个全职员工。XX 用 10 分钟自动出报表，设一次，每周一准时送到。

### AIDA：注意 → 兴趣 → 欲望 → 行动
适合首页、认知类内容、长文案。

### BAB：之前 → 之后 → 桥
适合案例、见证框架、邮件序列。
```
[之前]：现在难受的状态
[之后]：想要的状态
[桥]：你的产品怎么带他们到那里
```

### 4 Ps：承诺 → 画面 → 证明 → 推动
适合销售页、功能页、新品发布。

### QUEST：筛选 → 共鸣 → 教育 → 激发 → 过渡
适合长内容、直播/讲座脚本、培育序列。

## 标题公式库

每轮至少出 5 个不同公式的标题，再挑最强的。

**结果前置型**
```
[达成结果] 不用 [痛点]
```
"不用写代码也能做出落地页"
"不用等 4 个月就招到高级工程师"

```
[达成结果] 只要 [时间]
```
"90 天拉到你的头 1000 个客户"

**问题前置型**
```
别 [痛点] 了，开始 [想要的状态]
```
"别猜哪个有效了，开始看数据"

```
[痛点] 正在让你付出 [具体代价]
```
"手动做报表，一年烧掉你 200 小时"

**品类定义型**
```
专为 [特定人群] 的 [品类]
```
"给产品经理做的数据分析平台"
"给讨厌 CRM 的创始人的 CRM"

```
[品类]，但 [关键差异]
```
"项目管理，但为远程团队而生"

**见证型**
```
[数量] 个 [人群] 都在 [结果]
```
"2847 个团队靠它跑得更快"

**提问型**
```
[戳中痛点的问题]？
```
"还在用周末做周报吗？"

## CTA 框架

公式：`[动作动词] + [得到什么] + [必要限定]`

强弱谱：
| 弱（避免） | 中 | 强（用） |
|-----------|----|---------|
| 提交 | 免费试用 | 开始 14 天免费试用 |
| 了解更多 | 立即开始 | 免费领取完整清单 |
| 联系我们 | 预约演示 | 看看 XX 实际效果 |

**按用户阶段调门槛**：冷访客（首次）→ 低门槛"看看它怎么工作"；温访客（回过）→ "开始免费试用"；热访客（看定价）→ "立即开始"；流失用户 → "从上次进度接着来"。

CTA 下面加降低门槛的话："无需绑卡""14 天免费随时取消""2 分钟搞定""已有 2847 个团队在用它"。

## 异议处理

在读者最容易犹豫的地方（报价、下单前、靠近 CTA）放对应回应：

| 常见异议 | 放哪 | 文案写法 |
|---------|------|---------|
| "太贵了" | 定价页/FAQ | ROI 换算："一小时省 X 元，等于每月省 Z" |
| "不确定有没有用" | 见证区 | 带具体数字的实名客户反馈 |
| "会不会很麻烦" | 怎么用那段 | "3 步、10 分钟、不用写代码" |
| "不喜欢能退吗" | CTA 附近 | "30 天无理由退款" |
| "我得问下团队" | CTA 附近 | "把免费试用发给团队一起看" |
| "安全吗" | 信任区 | "SOP 2、GDPR、ISO 27001" |

风险逆转靠近 CTA：限时退款、免绑卡试用、随时取消、成功保证。

## 按内容类型给结构

**落地页**：首屏标题和流量来源一致（广告带来什么词，标题就呼应什么）→ 一句话价值主张 → 2-3 条痛点 → 方案（卖点转利益点）→ 见证 → 一次 CTA → 风险逆转。

**产品介绍**：先说"它是干嘛的 + 为什么重要"，再每个功能都能用"哪意味着……"连到利益点。每段一句话讲清一个卖点。

**定价页**：先一句话把价格和价值的关联点明（"按月付相当于一顿工作餐"），再多个档位对比、高亮推荐档、FAQ 处理"能不能换档/试用后呢"、企业档 CTA。

## 打磨与自检

1. **先定 CTA 再动笔**——每一句都在为那个动作服务。
2. **数一数"我们/我司"开头的句子**——改成以"你"开头。
3. **第二遍砍 30%**——初稿总是太长。
4. **形容词换成证据**——"很快"没意义，"200ms 加载"才有意义。
5. **标题要去流量来源**——标题和广告/链接对不上会让人秒退。
6. **靠近 CTA 放证明**——下单那一秒最需要降低犹豫。

## 配合

- 需要**打磨已写好的文案** → 用 Copy Editing（七遍法）。
- 需要**扣品牌调性** → 用 Brand Voice。
- 需要**平台化（小红书/短视频口播/公众号）** → 用 Social Copy。
