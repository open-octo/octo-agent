# Skill: legal-drafting

撰写一份能直接使用（或稍加核实即可使用）的中国大陆法律文书。产出是草稿，不是
最终定稿——涉及具体金额、管辖法院、法律依据的地方，标注清楚"待核实/待补充"，
不要替用户编造具体数字或杜撰不确定的事实。

## 第一步：确定文书类型

### 案由匹配（民商事案件）

先确定案由，案由决定了法律关系的定性，进而影响文书怎么写：

1. **识别法律关系**：双方是否签了合同？→合同关系；有人身/财产损害？→侵权
   关系；涉及婚姻家庭？→婚姻家庭关系。
2. **匹配大类**：常见大类包括人格权纠纷、婚姻家庭纠纷、合同纠纷（买卖/借款/
   租赁/承揽/建设工程/运输/保管/委托/技术服务等）、侵权责任纠纷（交通事故/
   医疗损害/产品责任/网络侵权等）、物权纠纷、劳动争议、知识产权纠纷、公司相关
   纠纷、票据纠纷、保险纠纷等，参照《民事案件案由规定》确认具体归类。
3. **确定具体案由**：优先选最具体的案由，不用笼统案由（例如"借贷纠纷"应写
   "民间借贷纠纷"而不是"欠款纠纷"——欠款可能是多种法律关系导致的，不等于
   借贷）。
4. **交叉验证**：该案由的适用条件是否满足？对方主体是否符合要求？是否有
   专属管辖规定？

合同纠纷/侵权责任竞合时，向用户说明可以择一起诉，并给出各自的利弊而不是替
用户悄悄做决定。

### 诉讼阶段 + 当事人地位 → 文书类型

先确定案件处于哪个阶段，再结合用户的诉讼地位确定文书类型：

| 阶段 | 当事人地位 | 文书类型 |
|---|---|---|
| 仲裁 | 申请人 | 商事仲裁申请书 |
| 仲裁 | 被申请人 | 仲裁答辩书 |
| 一审 | 原告 | 起诉状 |
| 一审 | 被告 | 答辩状 |
| 一审 | 反诉原告 | 反诉状 |
| 一审 | 反诉被告 | 反诉答辩状 |
| 二审 | 上诉人 | 上诉状 |
| 二审 | 被上诉人 | 上诉答辩状 |
| 再审 | 再审申请人 | 再审申请书 |
| 再审 | 被申请人 | 再审答辩状 |
| 执行 | 申请执行人 | 强制执行申请书 |
| 执行 | 被执行人 | 执行异议申请书 |
| 保全 | 申请人 | 财产保全申请书 |
| 保全 | 被申请人 | 保全异议申请书 |

不确定阶段或地位时先问用户，不要凭猜测直接开始起草。

## 通用排版规范

中国大陆法院诉讼文书的通行排版惯例：

- 标题：宋体加粗二号，居中
- 正文：仿宋小三号
- 行距：28磅，段前段后0
- 首行缩进：2字符

用 `write_file` 产出 Markdown/文本草稿时，在文末注明这套排版规范，方便用户
拿去 Word 里排版；本技能不直接生成排版好的 .docx 文件。

## 诉讼文书

### 起诉状

```
民事起诉状

原告：[姓名/名称]，[性别]，[出生日期]，[民族]，
住所地：[地址]
统一社会信用代码/身份证号：[代码/号码]
法定代表人：[姓名]，[职务]
委托诉讼代理人：[姓名]，[律所名称]律师

被告：[姓名/名称]，[性别]，[出生日期]，[民族]，
住所地：[地址]
统一社会信用代码/身份证号：[代码/号码]

诉讼请求：

一、判令被告[具体请求]；
二、判令被告承担本案全部诉讼费用。

（暂计标的额：人民币[金额]元）

事实与理由：

[签约情况] [合同核心条款] [履行情况] [违约事实/争议事实] [催告/协商情况]

综上所述，原告依据《中华人民共和国民法典》第XXX条等相关规定，诉至贵院，望判如所请！

此致
[法院名称]

具状人：[原告名称]
[日期：年 月 日]
```

**诉讼请求写法：**
- 暂计标的额在请求后用括号标注
- 违约金按"基数→利率→起算→截止→暂计"的顺序表述，例如："以XX元为基数，
  自XXXX年XX月XX日起按全国银行间同业拆借中心公布的一年期贷款市场报价利率
  （LPR）的X倍计算至实际清偿之日止，暂计至XXXX年XX月XX日为XX元"（LPR统一
  小写）
- 诉讼费作为独立一项列在最后
- 给付之诉 > 确认之诉 > 形成之诉，按此优先顺序排列多项请求

**事实与理由三段式：** ①签约（时间+合同名称+核心条款摘要）②履行（"上述合同
签订后，……"+具体履约细节）③违约+催告（违约事实→催告经过→"故诉至贵院，
望判如所请"）

**注意：** 法条引用宜少不宜多；案由提交前需再次确认；管辖法院要同时确认
级别管辖和地域管辖；提醒用户保留证据原件备查。

### 答辩状

```
民事答辩状

答辩人（被告）：[名称/姓名]
住所地：[地址]
被答辩人（原告）：[名称/姓名]
住所地：[地址]

因答辩人与被答辩人[案由]纠纷一案（案号：[案号]），答辩人现提出答辩如下：

答辩意见

不同意被答辩人的全部诉讼请求，望贵院依法驳回。

一、[具体答辩意见1——事实层面]
二、[具体答辩意见2——法律层面]
三、[具体答辩意见3——金额/计算层面]

综上所述，答辩人认为被答辩人的诉讼请求缺乏事实和法律依据，请求贵院依法驳回。

此致
[法院名称]

答辩人：[答辩人名称]
[日期：年 月 日]
```

**答辩意见前置**：开篇即表态"不同意全部诉请，望贵院依法驳回"，结论先行再
分点论证。

**论证策略分三层**：事实层面（对原告诉称事实逐一回应：认可/部分认可/否认）
→法律层面（法律适用、责任构成、举证责任分配）→金额/计算层面（逐项核对
质疑对方主张的金额）。

**不要做的事**：❌不附证据清单（证据单独提交）❌不单独列诉讼费（由法院决定）
❌不替对方计算费用 ❌不用"答辩人认为被答辩人之诉请毫无事实与法律依据"这类
空洞套话开头。答辩意见要精准到法条的款、项，不能只笼统说"违反相关法律规定"。

如涉及交通事故案件，额外关注：责任比例力争降低己方比例、依据道路交通事故
司法解释相关规定审查对方保险情况、交强险→商业三者险→侵权人的赔付层级分析、
己方如有损失注意保留另案追偿权利的表述。

### 反诉状

```
民事反诉状

反诉原告（本诉被告）：[名称/姓名]
反诉被告（本诉原告）：[名称/姓名]

反诉请求：
一、判令反诉被告[具体请求]；
二、判令反诉被告承担本案反诉部分全部诉讼费用。
（反诉标的额：人民币[金额]元）

事实与理由：
...

此致
[法院名称]

反诉人：[反诉人名称]
[日期：年 月 日]
```

关键点：当事人标注要写清"反诉原告（本诉被告）"和"反诉被告（本诉原告）"；
标的额在请求后合计标注；损失明细用表格呈现；法条引用少而精。

### 上诉状

```
民事上诉状

上诉人（原审×告）：[名称/姓名]
被上诉人（原审×告）：[名称/姓名]

上诉人因与被上诉人[案由]纠纷一案，不服[法院名称]（XXXX）XX民初XX号民事
判决/裁定，现提起上诉。

上诉请求：
一、撤销[法院名称]（XXXX）XX民初XX号民事判决第X项；
二、依法改判[具体请求]；
三、本案一、二审诉讼费用由被上诉人承担。

上诉理由：
一、一审判决认定事实错误：[具体指出]
二、一审判决适用法律错误：[具体指出]
三、[其他上诉理由]

此致
[二审法院名称]

上诉人：[上诉人名称]
[日期：年 月 日]
```

公文格式，不用三段式；上诉请求要精确到撤销/改判的具体项；上诉理由按
事实错误→法律错误→程序错误分层论述；提醒用户附一审判决书复印件。

### 再审申请书

```
再审申请书

再审申请人（原审×告）：[名称/姓名]
被申请人（原审×告）：[名称/姓名]

再审申请人因与被申请人[案由]纠纷一案，不服[法院名称]（XXXX）XX民初XX号/
[中院]（XXXX）XX民终XX号民事判决/裁定，现依法申请再审。

再审请求：
一、撤销[原判决/裁定]；
二、依法改判[具体请求]或发回重审。

法定事由：
依据《中华人民共和国民事诉讼法》关于再审事由的规定，[具体说明符合的事由]：
一、有新的证据，足以推翻原判决、裁定的
二、原判决、裁定认定的基本事实缺乏证据证明的
三、原判决、裁定认定事实的主要证据是伪造的
四、原判决、裁定适用法律确有错误的

此致
[法院名称]

再审申请人：[申请人名称]
[日期：年 月 日]
```

**五步法**：事由→当事人→请求→论证结构→层次。引用具体再审事由条款前，
用 `legal-search` 核实现行有效的条文号，法律修订会调整条号。

### 强制执行申请书

```
强制执行申请书

申请执行人：[名称/姓名]
被执行人：[名称/姓名]

申请执行人依据已经发生法律效力的[法院名称]（XXXX）XX民初XX号民事判决/调解
书，申请强制执行。

执行依据：[法院名称]（XXXX）XX民初XX号民事判决/调解书

执行请求：
一、强制被执行人向申请执行人支付人民币[金额]元；
二、强制被执行人加倍支付迟延履行期间的债务利息；
三、强制被执行人承担本案执行费用。

事实与理由：
[法院名称]（XXXX）XX民初XX号民事判决/调解书已于XXXX年XX月XX日发生法律
效力，被执行人至今未履行/未完全履行生效法律文书确定的义务，故申请强制执行。

此致
[有管辖权的法院]

申请执行人：[名称]
[日期：年 月 日]
```

### 代理词

```
代理词

审判长、审判员：

[律师事务所名称]接受[当事人名称]的委托，指派[律师姓名]律师担任其诉讼代理人，
现就本案发表如下代理意见：

一、[论点——论据]
依据《中华人民共和国民法典》第XXX条第X款的规定，[论证内容]

二、[论点——论据]
...

综上所述，[总结观点]，请求贵院依法予以支持。

此致
[法院名称]

代理人：[律师事务所]
[律师姓名] 律师
[日期：年 月 日]
```

论证内容可以先用 `legal-reasoning` 技能把 IRAC 论证搭好，再套进代理词的
格式里，不用重新组织论证逻辑。

```
[法院名称]
```

### 商事仲裁申请书

```
商事仲裁申请书

申请人：[名称/姓名]
被申请人：[名称/姓名]

依据申请人与被申请人于XXXX年XX月XX日签订的《[合同名称]》第X条中约定的
仲裁条款/双方于XXXX年XX月XX日达成的仲裁协议，申请人现向[仲裁委员会名称]
申请仲裁。

仲裁申请事项：
一、裁决被申请人[具体请求]；
二、裁决被申请人承担本案全部仲裁费用。
（暂计标的额：人民币[金额]元）

事实与理由：
[三段式：签约→履行→违约+申请仲裁]

此致
[仲裁委员会名称]

申请人：[名称]
[日期：年 月 日]
```

**从起诉状改写为仲裁申请书的术语替换表：**

| 诉讼术语 | 仲裁术语 |
|---|---|
| 起诉状 | 仲裁申请书 |
| 原告/被告 | 申请人/被申请人 |
| 诉讼请求 | 仲裁申请事项 |
| 此致[法院] | 此致[仲裁委] |
| 具状人 | 申请人 |

三段式沿用签约→履行→违约，结尾改为"故申请仲裁，望裁如所请"；如有仲裁
条款，在事实段注明。

## 非诉文书

### 律师函

```
律师函

[编号]：[律所简称]函字（XXXX）第XX号

致：[收件人全称]

[律师事务所名称]（以下简称"本所"）依法接受[委托人全称]（以下简称"委托人"）
的委托，指派[律师姓名]律师（执业证号：[号码]）就[事由]相关事宜，特致函如下：

一、委托声明
本所受委托人委托，就[简述委托事项]之相关法律问题，郑重致函贵方。

二、基本事实
[按时间顺序客观陈述事实经过]

三、法律依据
依据《中华人民共和国民法典》第XXX条[及其他相关法律条文]的规定，[法律分析]

四、要求
基于上述事实和法律，委托人要求贵方：
1. [具体第1项要求，包括金额、期限]
2. [具体第2项要求]

五、后果告知
如贵方在上述期限内未能满足委托人的合理要求，委托人将依法采取[诉讼/仲裁/
其他法律手段]等措施追究贵方的法律责任。

专此函告，望贵方慎重考虑！

[律师事务所名称]
承办律师：[律师姓名]
[日期：年 月 日]
```

关键点：编号统一用"律所简称+年度+序号"格式；事实按客观时间顺序陈述，不加
主观评论；要求要明确金额和期限；后果告知要具体且合理，不要空泛威胁。

适用场景：投融资交易、并购重组、股权激励、合规专项意见等需要正式法律意见

## 合同起草

### 标准结构（16项）

```
合同名称
（合同编号：[编号]）

甲方：[名称] / 统一社会信用代码/身份证号 / 法定代表人 / 住所地 / 联系电话
乙方：[同上]

（鉴于条款——背景说明）

第一条 定义（可选，复杂合同才需要）
第二条 标的/服务内容
第三条 价款与支付
第四条 履行期限与方式
第五条 双方权利义务
第六条 验收标准与方法
第七条 保密义务
第八条 知识产权
第九条 违约责任
第十条 不可抗力
第十一条 争议解决

第十三条 其他约定
```

### 核心条款起草要点

**违约责任**：违约金比例一般不超过合同总金额的30%；迟延履行违约金参考
日万分之三至万分之五；建议约定责任上限（如"累计不超过合同总价的XX%"）；
考虑增加间接损害排除条款。

**争议解决**：
- 诉讼约定示例："因本合同引起的或与本合同有关的任何争议，双方应友好协商
  解决；协商不成的，任何一方均有权向[甲方/乙方]住所地有管辖权的人民法院
  提起诉讼"
- 仲裁约定示例："……任何一方均有权提交[仲裁委员会名称]按照其仲裁规则进行
  仲裁。仲裁裁决是终局的，对双方均有约束力"

**保密条款**：明确定义保密信息范围；保密期限一般为合同终止后2-3年；列明
例外情形（已公开、独立开发、法律规定披露）。

**知识产权**：背景IP（合同签订前已有的知识产权）各方保留归属；前景IP
（履行中新产生的知识产权）明确归属约定；涉及许可使用另一方IP的，明确
许可范围和条件。

**通知与送达**：明确送达地址、邮箱、联系人；约定送达生效规则（邮寄后X日
视为送达/邮件发送即视为送达）；建议注明双方同意上述地址作为司法文书送达
地址，减少诉讼阶段的送达争议。

审查已有合同（而不是起草新合同）用 `contract-review` 技能。

## 文书法条引用策略

不同文书对法条引用的密度要求不同，不要一刀切：

- **起诉状**：宜少不宜多，点出核心请求权基础即可，过多引用反而显得诉求
  不聚焦
- **答辩状/代理词**：精准到法条的款、项，越具体越有说服力
- **反诉状**：少而精
- **法律意见书**：完整、系统，先列法条原文再逐项分析

任何具体条文引用前，用 `legal-search` 核实现行有效版本，不要凭训练知识
里的印象写死条号——法律会修订，条号会变化。

## 边界

- 产出的是可编辑草稿，涉及具体的当事人信息、金额、日期、案号的地方留空
  给用户填写或标注"待补充"，不要杜撰事实性内容。
- 不做管辖法院/仲裁委的最终确定——给出判断依据，最终以用户提供的信息或
  专业律师核实为准。
- 不生成排版好的 .docx 文件——只产出带排版规范说明的文本/Markdown 草稿。
