# Skill: visa-checklist

签证政策因目的国、申请人国籍、签证类型（旅游/商务/过境/工作）而完全不同，
而且经常变——不是一套可以背下来直接套用的规则。这个技能的核心不是"知道
每个国家的签证要求"，是"问对变量、系统性检索、不确定就说不确定"。

## 第一步：确定三个变量

在给出任何材料清单之前，先确认：

1. **目的国**：去哪个国家/地区
2. **申请人国籍**（有时还需要居住地/常住国，免签政策经常按国籍+居住地
   组合判断，不是只看护照）
3. **签证类型**：旅游、商务、过境、探亲、工作等——不同类型材料要求
   差异很大

任何一个变量缺失，先问用户，不要假设。同一个目的国，不同国籍的免签/
落地签/需要提前办签证的情况可能完全不同。

## 第二步：检索确认，不要凭印象

签证政策是这个技能里最容易出错、也最容易造成实际损失的地方——材料准备
错了可能导致签证被拒或者到了机场被拒绝登机。

- 优先检索目的国官方使领馆网站或官方签证服务网站（很多国家有官方指定的
  签证代办机构网站，比如印度的VFS Global、部分国家的电子签证官网）。
- 检索不到官方原文、或者信息看起来可能过时时，明确告诉用户"建议直接去
  官方使领馆网站核实最新要求，签证政策变化频繁"，不要用训练知识里可能
  已经过时的印象给出具体材料清单当作确定信息。
- 如果用户国籍在目的国有免签或落地签政策，同样要核实停留天数上限、
  是否需要回程机票、是否需要酒店预订证明这些细节——"免签"不等于
  "不需要任何材料"。

## 第三步：按结构整理清单

确认信息来源可靠后，按这个结构组织：

```markdown
# [目的国] 签证/入境材料清单

**签证类型：** [旅游/商务/过境/...]
**适用国籍：** [用户的国籍]
**签证方式：** [免签/落地签/电子签/使领馆签证]
**信息来源：** [官方网站链接] （核实日期：[日期]）

## 必备材料

- [ ] 护照（有效期要求：距离行程结束后至少还剩几个月，具体见来源）
- [ ] 签证申请表（如需要）
- [ ] 照片（规格要求）
- [ ] [其他必备材料]

## 视情况需要

- [ ] 往返机票预订证明
- [ ] 酒店预订证明/行程单
- [ ] 银行流水/资金证明
- [ ] 邀请函（商务/探亲）
- [ ] 旅行保险
- [ ] [其他条件性材料]

## 时间线提醒

- 建议提前多久申请：[根据来源信息]
- 停留天数上限：[如适用]
- 落地签/电子签的现场排队时间预估（如适用）

## 免责提醒

签证政策可能随时调整，以上信息核实于[日期]，出行前请以目的国官方使领馆
或官方签证网站的最新公告为准。
```

## 常见坑点提醒

- **"免签"不等于"随便进"**：免签通常仍有停留天数限制、可能要求出示
  回程机票和资金证明，入境官员仍有权拒绝入境。
- **护照有效期陷阱**：很多国家要求护照有效期覆盖行程结束后至少6个月，
  不是覆盖到行程结束当天就够。
- **过境签容易被忽略**：转机时间长、或者需要出机场的转机，可能需要
  单独的过境签，不能默认"只是转机不需要签证"。
- **多次往返 vs 单次入境**：签证类型里"单次"和"多次往返"差别很大，
  用户如果行程中有出境再入境的安排（比如从A国去B国再回A国），要提前
  确认签证是否支持。

## 边界

- 不给出未经检索确认的具体材料清单当作确定信息——这个技能存在的意义
  就是防止"我记得大概需要这些"这种凭印象的回答造成实际损失。
- 不判断"这个材料够不够"——最终审核权在使领馆/边检，这个技能只负责
  系统性整理清单和提醒常见坑点。
