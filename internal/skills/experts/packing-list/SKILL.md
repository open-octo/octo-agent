# Skill: packing-list

一份好的打包清单不是"衣服、洗漱用品、充电器"这种放之四海而皆准的列表，
是按这次出行的具体情况——去哪、干什么、和谁去——推导出来的。这个技能先
问清楚决定清单内容的变量，再按变量分层生成。

## 第一步：确定决定清单的变量

- **目的地气候**：出行当月的气温范围、是否多雨、湿度、昼夜温差
- **行程类型**：城市观光、徒步/户外、商务、海滨度假、滑雪、长途背包等
  ——不同类型对装备的要求差别很大
- **人群构成**：独自出行、情侣、带娃、带老人——影响需要额外准备的物品
  （儿童用品、常用药、辅助行走装备等）
- **行程天数**：影响衣物数量和是否需要考虑当地洗衣
- **交通方式**：飞机（有行李限重/违禁品规定）还是自驾（限制更少）
- **住宿类型**：酒店（提供洗漱用品）还是民宿/露营（可能什么都要自备）

任何一项不清楚就先问，不要用一份通用清单敷衍——"帮我列个行程清单"这种
请求看起来简单，但气候和行程类型不同，清单内容可能完全不一样。

## 第二步：按分层结构生成清单

```markdown
# [目的地] 打包清单（[天数]天，[行程类型]）

## 证件与财务
- [ ] 护照/身份证
- [ ] 签证材料（如需要，参考 visa-checklist）
- [ ] 现金+信用卡
- [ ] 保险单据

## 电子设备
- [ ] 手机+充电器
- [ ] 转换插头（如目的国插座标准不同）
- [ ] 充电宝（注意随身/托运限重规定）
- [ ] [按行程类型追加：相机、行动记录仪等]

## 衣物（按气候+天数推算）
- [ ] [按当地气温给出具体建议：比如"平均气温XX度，建议XX件薄外套+XX件
  短袖"，而不是笼统的"多带几件衣服"]
- [ ] [按行程类型追加：徒步鞋、泳衣、正装等]

## 洗漱与健康
- [ ] 常规洗漱用品（住酒店可精简，住民宿/露营需要自备齐全）
- [ ] 常用药品（感冒药、肠胃药、晕车药，按目的地卫生条件适当加强）
- [ ] 防晒/驱蚊（按目的地气候和季节判断是否需要）
- [ ] [带娃：儿童常用药、退烧药；带老人：常规处方药备足用量]

## 行程类型专项
- [ ] [户外/徒步：登山杖、头灯、急救包、保暖层]
- [ ] [海滨：泳衣、沙滩巾、防水袋]
- [ ] [滑雪：保暖装备、护目镜（滑雪场可租的装备不用带）]
- [ ] [商务：正装、名片、笔记本电脑]

## 特殊人群

### 带娃
- [ ] 儿童常用药+体温计
- [ ] 娱乐用品（长途交通工具上的安抚物品）
- [ ] 尿布/湿巾（视年龄）

### 带老人
- [ ] 常规处方药（按行程天数备足，建议多备几天用量以防延误）
- [ ] 病历/用药清单（英文版，以防境外就医需要）
- [ ] 舒适度相关装备（颈枕、辅助行走工具）

## 交通限制提醒

- 如果是飞机出行：核对随身/托运行李限重限尺寸、液体限制（100ml装+
  透明袋）、锂电池/充电宝的随身携带规定（通常不能托运）
- 如果目的国有特殊入境限制（比如某些国家限制携带特定药品、食品），
  提醒用户提前核实
```

## 生成原则

- **具体，不笼统。** "带几件衣服"要落到"按当地平均气温给出具体建议"，
  不是"多带几件"。
- **按行程类型分层，不是一次性列完。** 通用类目（证件、电子设备、洗漱）
  和行程类型专项（徒步/海滨/滑雪/商务）分开列，避免不相关的装备也塞
  进清单里。
- **特殊人群单独成组。** 带娃、带老人的额外需求单独列一节，不要混在
  通用清单里让用户自己筛。
- **交通/入境限制单独提醒。** 液体限制、锂电池托运规定、目的国特殊
  入境限制这类"清单之外但同样重要"的信息，单独一节提醒，不要漏掉。

## 边界

- 具体的气温数据、当季天气特点，用 `web_search` 检索目的地当月的实际
  气候数据，不要凭训练知识里的印象给可能过时的季节性描述。
- 不臆造目的国的入境限制细节（比如"某国禁止携带XX药品"这类具体规定）
  ——这类信息如果需要给出，先检索确认或建议用户核实，不确定就明确说
  不确定。
