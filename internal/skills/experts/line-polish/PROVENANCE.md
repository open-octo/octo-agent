# Provenance audit — line-polish

## Source

`haowjy/creative-writing-skills`, path
`skills/story-review/resources/line-edit.md`
(https://github.com/haowjy/creative-writing-skills, commit
`fd7a3ad9cd7697a0645ff6ff4bd5e809cf7673a3`), Apache License 2.0. As with
`structural-diagnosis`, the repository's root `LICENSE` file leaves the
Apache 2.0 copyright placeholder unfilled; attribution is to the
repository maintainer.

## What the source actually is

The sentence/paragraph-level review resource in the same `story-review`
skill used for `structural-diagnosis` — covers voice, rhythm, clarity,
texture, subtext, and redundancy at the prose-execution level, distinct
from the structural/developmental levels.

## What was reused

- **"Learn the voice before you touch it"**: read enough of the project to
  know the author's characteristic rhythms, vocabulary range, and register
  before editing, so the edit doesn't normalize the voice into generic
  prose.
- **"Name patterns, not every instance"**: find 3-4 recurring patterns
  rather than cataloging every sentence.
- **The six check dimensions**: voice, rhythm, clarity, texture, subtext,
  redundancy — kept as a checklist, with "subtext" narrowed to apply only
  when the piece includes dialogue/quoted material (a fiction-specific
  check that has a real but narrower non-fiction analog).
- **The redundancy insight, reused near-verbatim**: "this is the single
  most common line-level failure in AI-generated prose: the text does the
  work, then a sentence explains what the work accomplished." This is
  quoted-in-substance rather than paraphrased away, because it names a
  specific, verifiable, and highly actionable failure mode that applies
  directly to AI-assisted non-fiction writing (arguably more so than to
  fiction, which was the source's original context).
- **The report format**: name the pattern, state the reader cost, give 2-3
  representative examples with locations, describe the direction of a fix
  using outcome language ("sharper POV", "cleaner image") rather than bare
  criticism.
- **The preserve-deliberate-choices caveat**: don't flatten intentional
  roughness, ambiguity, or repetition that serves the voice; ask rather
  than correct when unsure if something is a choice.

## What was changed

- "POV, character, genre" as components of voice — generalized to "语域
  (register)、语气 (tone)、项目风格 (piece style)", since non-fiction has
  no character/POV in the fictional sense.
- Subtext check — narrowed from "dialogue carrying more than surface
  information between characters" to a bracketed, conditional check that
  only applies "如果是对话/引用体写作" (if the piece includes dialogue or
  quotation), since most non-fiction has no dialogue at all.

## What was not reused

The other `story-review` resources (`copyedit.md`, `proofreading.md`,
`prose-critique.md` and its per-focus-area files) were not read in depth
for this skill; they cover adjacent but distinct review levels
(grammar/mechanics, adversarial craft critique) not in scope for this
adaptation round.

## Conclusion

A close, largely verbatim-in-substance translation of a well-designed
line-level review methodology, generalized from fiction to any long-form
prose by narrowing (not force-mapping) the one check — subtext — that has
no universal non-fiction equivalent.
