新建会话时看到的那一屏给了四个入口：看懂一个项目、做个功能或小工具、查资料做调研、写点东西。
四张里有两张是冲着代码去的，而 octo 不只是拿来写代码的——用它的人比我们更清楚自己的四件事
是什么。做法务的那四张，和做内容的那四张，不会是同一批。

`~/.octo/landing.json` 可以把它们整个换掉。

```json
{
  "title": "今天动哪块？",
  "subtitle": "挑一个，或者直接开始输入。",
  "cards": [
    {
      "icon": "🔍",
      "title": "拆解一条笔记",
      "prompt": "帮我拆解这条笔记：钩子、结构、为什么能火。"
    },
    {
      "icon": "ant-design:file-text-outlined",
      "title": "审一份合同",
      "prompt": "帮我看这份合同，告诉我哪些地方需要注意。"
    }
  ]
}
```

刷新 Web UI 就能看到。删掉这个文件，内置那四张就回来了。

| 字段 | 说明 |
| --- | --- |
| `title` | 大标题。不写就用内置的（内置的有中英翻译）。 |
| `subtitle` | 标题下面那行。同上。 |
| `cards` | 整个替换四张卡。最多 8 张；列数跟着数量走，超过四张会换行。 |
| `cards[].title` | 卡片上的标题。必填。 |
| `cards[].prompt` | 点它之后填进输入框的内容。必填。 |
| `cards[].icon` | [iconify](https://icon-sets.iconify.design/) 图标名（如 `ant-design:tool-outlined`），或者一个 emoji——不含 `:` 的一律当文字画。可选。 |

## 点一下卡片会发生什么

它**只是把 prompt 填进输入框，不发送**。这是有意的：下面的工作目录和模型选择器仍然有效，
你还可以先改几个字再发。入口是个起点，不是绕过这些控件的快捷方式。

所以一段好的 prompt 读起来应该像你本来就会打的第一句话——包括那些你反正都要补充的部分
（「先问我读者是谁」「动手之前先跟我对一遍思路」）。

## 几条值得知道的规则

- **是替换，不是合并。** 你的四张不等于内置四张加上你的。替一半的结果谁都不认。
- **你写什么就显示什么。** 内置卡片走 octo 的 i18n 有中英两版；你写的是你的，
  用什么语言写就用什么语言显示。
- **文件写坏了，丢的是定制而不是这一屏。** JSON 格式错、某张卡没写 prompt、标题写了 400 字——
  各自被丢弃或截断，最后你落在内置那一屏，而不是一个报错页。这是个你手改的文件，
  写漏一个逗号是常态而不是意外。

## 顺带一提

这里改的是**内容**。同一屏的**外观**——背景、强调色、字体——由主题决定，两者是叠加的：
见[制作主题](/docs/zh/guides/themes/)。
